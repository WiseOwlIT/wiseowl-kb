Updates stuck or repeatedly failing? This batch script resets several Windows Update components so you can restart your PC and try again. Try the Windows Update troubleshooter first; use this reset when simpler troubleshooting has not helped.

**Script type:** Windows batch (`.bat`) · **Run as:** Administrator · **Restart required:** Yes

## Before you start

Save your work and let any active update installation finish. On a work-managed device, check with your IT team before changing update or network settings.

:::caution What this script changes
It stops and starts Windows Update, Cryptographic Services, BITS and Windows Installer; renames the update cache folders; resets BITS and Windows Update service permissions; resets Winsock and the WinHTTP proxy; and attempts to re-register DLLs.

The permission resets replace custom service permissions. The proxy reset removes the configured WinHTTP proxy, which may be needed on your network. Record any custom settings before running this script. See [Microsoft’s Windows Update reset guidance](https://learn.microsoft.com/en-us/troubleshoot/windows-client/installing-updates-features-roles/additional-resources-for-windows-update).
:::

## Run it step by step

1. If you copied the code, open **Notepad** and paste it into a new file.
2. Choose **File → Save As**, set **Save as type** to **All files**, and name it `reset-windows-update.bat`. Make sure it does not end in `.bat.txt`. If you downloaded the file, you can skip these two steps.
3. Right-click the saved `.bat` file and choose **Run as administrator**. Approve the Windows permission prompt.
4. Read the messages in the command window. The script pauses at the end so you can review them before closing it.
5. Restart your PC, then open **Settings → Windows Update → Check for updates**.

:::note A “Done” message does not confirm every step succeeded
This is the supplied script, unchanged. It continues after command failures, and DLL registration uses silent mode. Some listed DLLs may be absent on newer Windows versions. If a `.old` folder already exists, its rename can fail; do not assume a second run has reset the cache successfully.
:::

## Check the result

Try the update that was failing and confirm it installs successfully. If it still fails, note the exact error code and any service or folder errors from the script. Those details are more useful for the next troubleshooting step than repeatedly running the reset.

This script has been reviewed for presentation here; it has not been executed or validated on a Windows test machine.
