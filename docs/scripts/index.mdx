Ever found yourself typing the same commands again and again? Scripts bring those steps together in a reusable file, helping you spend less time on repetitive work and more time solving the problem in front of you.

This library is a home for practical scripts covering Microsoft, VMware and networking. Each script has its own knowledge base article, so you can understand what it does before deciding whether it fits your task.

## How scripts can help

- **Save time on repeat tasks.** Keep a useful sequence of commands together instead of typing each one from scratch.
- **Make your process more consistent.** Follow the same steps each time, with fewer opportunities for a missed command or typing mistake.
- **Learn as you go.** Read the code alongside the explanation to understand how the commands work together.
- **Keep useful fixes close by.** Return to an article when you need its code, instructions or verification steps.

## What you’ll find in each article

Each article explains when the script is useful, what it changes and any permissions it needs. You can preview the full code, copy it or download the file, then follow the instructions to run it and check the result.

Take a moment to read the guidance first. Scripts run with your account’s permissions, and some make system changes. For a work-managed device, follow your organisation’s change process and try the script in a suitable test environment where possible.
